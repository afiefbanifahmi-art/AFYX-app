AFYX LANDING PAGE

Kandungan:
- index.html : landing page utama
- manifest.json : konfigurasi PWA
- service-worker.js : offline cache asas
- pwa/index.html : halaman PWA
- assets/afyx-logo.png : logo AFYX yang diekstrak daripada gambar diberikan
- assets/icon-192.png / icon-512.png : ikon PWA
- APK_LINK.txt : placeholder URL APK

NOTA APK:
Saya tidak boleh menghasilkan APK sebenar tanpa source/build projek Android. Letakkan URL APK sebenar dalam APK_LINK.txt
dan kemas kini href butang APK dalam index.html.

NOTA PWA:
Untuk install PWA, host folder ini melalui HTTPS (GitHub Pages, Netlify, Vercel atau hosting sendiri).
Kandungan produk dalam Gamma tidak dapat diekstrak sepenuhnya daripada URL dalam sesi ini, jadi teks landing page
disediakan sebagai versi AFYX yang boleh terus diedit.
